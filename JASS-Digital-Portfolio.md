# JASS Digital Portfolio

A curated portfolio of selected JASS Digital projects from the broader GitHub repository inventory.

## Portfolio Baseline

The accepted JASS Digital Portfolio Audit v2 identified:

- **378** total repositories
- **137** forks
- **55** original archived repositories
- **186** original active/non-archived repositories
- **32** portfolio candidates
- **7** strong portfolio candidates

This portfolio is intentionally curated. It is **not** a mirror of every GitHub repository.

## Portfolio Notes

The Audit v2 is a portfolio-readiness heuristic, not a measure of software quality. Its signals include README depth, recent activity, stars, descriptions, repository topics, homepage, release information and archive status.

The automated audit also surfaced two similarly named image-editor repositories:

- `toast_image_editor`
- `toast-image-editor`

These are intentionally **not** treated as two separate flagship portfolio entries in this curated list.

## Portfolio Philosophy

**Build broadly. Showcase selectively.**

The full GitHub inventory can remain large and historically rich. The public portfolio should emphasize the projects that best communicate JASS Digital's capabilities and identity.
